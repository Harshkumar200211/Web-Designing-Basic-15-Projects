## Run a project
1. Clone or download this repository.
2. Open any project folder.
3. Open its `index.html` in a browser or use VS Code Live Server.
4. Study the HTML, CSS and JavaScript files, then customise the project.

No build tools are required. The Bootstrap portfolio uses the Bootstrap 5.3.3 CDN. The photo gallery loads sample photos from Unsplash and needs an internet connection for images.

## Student practice
For every project, change the colours, add one feature, test it on a mobile screen and explain how its HTML structure, CSS styling and JavaScript behaviour work.

Each project folder contains its own README with run instructions and practice tasks.

**Made for classroom practice and beginner web-design learning.**
