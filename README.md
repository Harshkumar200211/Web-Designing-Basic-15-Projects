## How to run
1. Clone or download this repository.
2. Open any project folder.
3. Open its `index.html` in your browser, or use VS Code Live Server.
4. Read the HTML structure, then inspect CSS and JavaScript.
5. Change the design and add your own features.

No build tools or package installation are required. The Bootstrap portfolio uses Bootstrap 5.3.3 via CDN. Gallery photos are loaded from Unsplash and require an internet connection.

## Suggested learning path
- HTML and CSS layouts: 01, 02, 03, 08
- JavaScript fundamentals and DOM: 04, 05, 06, 07, 09, 12
- Browser APIs and data handling: 11, 13
- Forms and calculations: 07, 14
- Bootstrap practice: 15

## Student practice
For each project:
- Identify the HTML elements used.
- Explain the important CSS properties.
- Change the colour scheme and layout.
- Add at least one small feature.
- Test on a mobile screen.

Every project folder has its own README with run instructions and practice tasks.

## Notes
These are classroom learning examples, not production services. The expense tracker does not connect to bank accounts; the weather dashboard does not fetch live weather; the form does not create real user accounts.

**Made for classroom practice and beginner web-design learning.**
